## Issue

Category filter was not working. Selecting any category (e.g., Identity) showed no documents even when matching documents existed in the vault.

---

## Root Cause

Wire-format mismatch between backend and frontend.

Rust Serde serialized DocumentCategory enum variants as PascalCase (Identity, Education). The frontend expected lowercase (identity, education). The comparison doc.category === selectedCategory always returned false.

---

## Fix

Added Serde attribute to the DocumentCategory enum:

#[serde(rename_all = "lowercase")]

---

## Regression Test Added

category_serializes_as_lowercase — asserts Identity serializes as "identity". Prevents future regressions if the attribute is removed. Test count: 68 to 69.
